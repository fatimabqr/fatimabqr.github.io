Customer Behavior Analytics Dashboard

Built five interactive Tableau dashboards analyzing customer purchasing patterns from 2021–2024 using the Superstore dataset. Applied cohort analysis and forecasting to evaluate customer retention trends, backing up the findings with a written report of data-driven business recommendations.

Stack Overflow Developer Survey EDA

Analyzed 43,700 records from the 2024–2025 Stack Overflow Developer Surveys of U.S. professional developers to evaluate compensation trends across 40 programming languages. Cleaned and aligned the data, then ran an exploratory analysis to surface high-value languages like Scala, Go, and Rust alongside high-growth languages like Dart (+27%), translating the results into curriculum recommendations for a coding bootcamp aimed at raising alumni starting salaries.

Python

Ctrl + Eat — Recipe Manager

F1 2026 Championship Prediction

A leakage-safe data pipeline over 1950–2026 Formula 1 race data, combining a custom Elo rating engine with an XGBoost learning-to-rank model to rank drivers within each race. Validated against a true holdout (the 2025 Championship and 2026 Dutch GP) and ran a 5,000-trial Monte Carlo simulation, calibrated on 2023–2025 walk-forward backtests, to forecast 2026 championship win probabilities and points — with A. K. Antonelli predicted to take the season.
